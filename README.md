# exclusion-display-audit: reproduction package

Generated by the Ohara autoresearch harness from campaign `exclusion-display-audit`. Every certified claim in `paper/` traces to the sealed, deterministic verifier shipped here and to the hits recorded in `ledger.jsonl`, re-checkable in one command.

## Reproduce (one command)

```
pip install -r requirements.txt
python reproduce.py
```

`reproduce.py` loads the sealed verifier (with its sibling modules), runs its own self-checks where it defines them (`selftest`, `dress_rehearsal`, `pre_search_checks`), and re-verifies every certified hit in `ledger.jsonl`, asserting each still returns `valid:True`. It exits 0 on success. Numbers in the paper that are enumeration or advisory outputs rather than sealed verdicts are labeled as such in the paper.

## Contents

- `workspace/`: the sealed verifier `workspace/verifier.py` (the sole oracle)
- `ledger.jsonl`: the hash-chained ledger: every run, claim, and certified hit
- `contract.json` / `CONTRACT.md`: the frozen public problem contract
- `PRIORS.md` / `JOURNAL.md` / `AUDIT.md`: belief state, decision trail, adversarial audit
- `FACTS.json`: every number in the paper, derived by the engine from the ledger
- `PREFLIGHT.md`: the deterministic check of the draft against those facts
- `paper/`: the LaTeX source and compiled PDF
- verifier/battery: search campaign: the sealed verifier is the public oracle and ships in workspace/ (no hidden battery).

## How it was produced

A pre-registered contract frozen before any grading, a blinded verifier as the sole oracle (nothing self-reported enters the ledger), independent re-verification of every claimed hit, and an adversarial multi-critic audit before the paper. The paper is human-authored (byline law) with an AI-contribution statement.
